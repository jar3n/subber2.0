Hello,

I decided to start this project because I did not like how algorithms were dictating who would appear in the subscriptions feed on Youtube. With this, I know that the latest videos from the people I want to watch will show up in the order they were published with the top being the most recent. 

To install the program, clone the repo into any folder.

If you would like to use this, you need to get an API key from Google because this program uses the Youtube API. Follow the link below for instructions on how to get a key.

https://developers.google.com/youtube/v3/getting-started

Once you have the key, make a file following the format below and put it in the repo head folder.

```
[key]
api key=YOURKEYHERE
```
